# cassyx — frontend

React 19 + TypeScript + Vite 6 application shell for cassyx (plan §2, Phase 0 workstream 3).

```
npm install
npm run dev        # Vite dev server on :5173, /api proxied to :8080
npm run build      # tsc --noEmit + production bundle
npm run test       # vitest + coverage (70% statements gate, plan §11.1)
npm run lint       # eslint + prettier --check
npm run gen:api    # regenerate src/api/schema.d.ts from ../openapi/cassyx-api.yaml
```

## Layout

```
src/
├── api/            transport: typed fetch wrapper, RFC 9457 errors, SSE, query client
│   ├── client.ts       ApiClient — base URL from env, timeouts, multipart, no secrets in URLs
│   ├── errors.ts       AppError + problem+json parsing
│   ├── sse.ts          SseParser + subscribeToJobEvents (job progress, plan §5.5)
│   ├── types.ts        hand-maintained domain types (regeneration-proof)
│   ├── endpoints.ts    the handful of endpoints the shell itself calls
│   └── schema.d.ts     GENERATED by `npm run gen:api` (placeholder until the spec lands)
├── theme/          cassyx identity: tokens, MUI theme, light/dark provider, logo
├── license/        LicenseGate, ActivationScreen, BypassBanner (plan §9)
├── connections/    connection form model, SecretField, Astra SCB flow (plan §3/§3.1)
├── schema/         SchemaTree + the identity model (plan §4)
├── layout/         AppShell, ConnectionBar, ResizableSidebar, TabBar, tab state (plan §8)
├── panels/         QueryEditor, DataGrid, JobsPanel, VectorPanel — Phase 1 fills these in
└── routes/         router + pages
```

## The OpenAPI client

`openapi/cassyx-api.yaml` is written by a different workstream and is a _build dependency_
(plan §2.3). Two rules follow:

- `src/api/schema.d.ts` is committed. Until the spec is complete it holds a hand-written
  placeholder so `build`, `test` and `tsc --noEmit` stay green.
- `npm run gen:api` overwrites it, and **fails loudly** rather than emitting an empty module:
  it checks the OpenAPI version is 3.1.x, that every `$ref`'d schema is defined, and that the
  generated output actually contains paths and schemas. A silently-empty generation would
  typecheck as `any` everywhere and hide the breakage. `npm run gen:api:optional` skips (exit 0)
  when the spec file is absent; CI's `contract` job uses the strict form.

Application code imports stable aliases from `src/api/types.ts`, not from the generated file
directly, so regeneration cannot break the shell.

## Design rules encoded here

- **Every schema node carries its own fully-qualified identity** (`{keyspace, table}`). Drag,
  selection and context menus resolve from `node.identity`, never from tree position. This is
  the fix for the prior-art bug where dragging `demo.users` produced
  `SELECT * FROM system_auth.users`. Guarded by tests in `src/schema/model.test.ts`.
- **Secrets are masked everywhere.** `SecretField` is used for both the Cassandra password and
  the Astra token; the token travels in request bodies only, and error text goes through
  `redactSecrets` before it can reach the UI.
- **The bypass banner is permanent.** When the API reports `edition: "unlicensed-bypass"` the app
  unlocks _and_ shows a non-dismissible banner (plan §9.2).
- **Light and dark are both first-class**, following the OS by default. The prior art was
  light-only.

## Docker

```
docker build -t cassyx-frontend .                  # nginx serving the static bundle on :8080
docker build --target dev -t cassyx-frontend:dev . # Vite HMR on :5173
```

The runtime image proxies `/api` to the `cassyx-api` service, with buffering disabled on
`/api/jobs/` so SSE progress frames are not held back until a job completes.
